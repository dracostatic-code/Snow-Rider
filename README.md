# Diamond Rush: Snowbound

A phone-first, installable PWA endless downhill game with 3D-style perspective graphics, swipe controls, generous diamond drops, and locally saved upgrades.

## Play on your Android phone

A PWA must be served from an HTTPS website to install and work offline. The ZIP contains the complete site.

### Easiest free hosting: GitHub Pages
1. Extract `diamond_rush_pwa.zip`.
2. Create a new public repository on GitHub (for example `diamond-rush`).
3. Upload the six files from this folder to the repository root.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish the site. Open the Pages URL on your Android phone in Chrome.
7. In Chrome, open the menu (⋮) and choose **Install app** or **Add to Home screen**.

The game stores diamonds, best distance, runs, and upgrade levels in local browser storage on that device. Clearing Chrome site data will reset that save.

## Controls
- Swipe left/right to change lanes.
- Swipe up to jump.
- Swipe down to duck.
- On-screen buttons are also available.

## Upgrades
- Diamond Magnet
- Gem Multiplier
- Crash Shield
- Pro Sled

No external libraries or paid services are required.
